# UEAP Conformance v0.2

A profile claiming UEAP conformance MUST document:

- event representation;
- canonicalization rules;
- commitment algorithm;
- proof type;
- issuer identity model;
- verification procedure;
- revocation model;
- provenance treatment;
- registry behavior, if used;
- security assumptions;
- domain-specific extensions.

Core conformance tests SHOULD include:

1. deterministic canonicalization;
2. deterministic commitment;
3. valid proof verification;
4. tamper rejection;
5. provenance preservation;
6. profile/version validation;
7. unknown issuer handling;
8. revoked attestation handling.
