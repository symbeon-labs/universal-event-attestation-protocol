# UEAP Terminology

| Term | Definition |
|---|---|
| Observation | Representation produced from an occurrence by an observer or system. |
| Evidence | Information supporting an observation or claim. |
| Canonical Representation | Deterministic representation used for cryptographic commitment. |
| Commitment | Cryptographic binding to a canonical representation. |
| Proof | Cryptographic material used to establish a declared property. |
| Attestation | Structured claim binding event, provenance, proof and metadata. |
| Issuer | Entity responsible for issuing an attestation. |
| Verifier | Entity or system evaluating an attestation. |
| Registry | Optional persistence layer for attestations. |
| Verified State | Structured result of verification under a declared policy/profile. |
| Domain Adapter | Component mapping domain-specific observations into UEAP structures. |
| Profile | Declared rules for representation, proof, verification and policy. |
